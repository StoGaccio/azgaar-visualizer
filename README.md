# Azgaar Visualizer

Un tool che permette di visualizzare con un file HTML le mapper che create con Azgaar e che esportate in .map.

Attualmente il codice è impostato per visualizzare una mia mappa, se volete modificarlo per mostrare le vostre dovrete:
1. Creare una repo di Github
2. Aggiungere nella repo il file .map e l'html
3. Alla riga 42 dell'html sostituire le informazioni del link con le proprie
  ```html
      src="https://azgaar.github.io/Fantasy-Map-Generator/?maplink=https://raw.githubusercontent.com/TUO-USERNAME/NOME-REPO/main/Grania.map&options=default"
  ```
Buon utilizzo!
